# Hydra-ESP-Flasher
It is a small project to make installing Hydra-ESP easier.

# Requirements
1. [Python 3.14](https://www.python.org/downloads/)
2. [Esptool](https://docs.espressif.com/projects/esptool/en/latest/esp32/)

# How to install 
1. Download the folder **Flasher Hydra**.

# How to use 
1. Open the folder **Flasher Hydra**.
2. Run the flasher for your operating system.
3. Enter your COM port where requested (e.g. `COM5` on Windows or `/dev/ttyUSB0` on Linux).
4. Click on **Flashing the ESP32** and wait.
5. If everything went well, this message will appear: `flashing completed successfully`.
